# LUMEN 작업 정리 — 체력·UI·사운드·모션·포탑

2026-10-14 · 이성진

## 요약

우선순위 4가지(체력 3칸, 방패·발열·구르기 UI, 모션·총기, 배경음·효과음)를 모두 반영했고, 적은 고정형 포탑으로 바꿨습니다. 마지막 수정들(총구 발사, 추가 사운드, 포탑 자기피격, 벽 조준선)은 **아직 빌드·플레이 테스트 전**입니다. 헤더가 바뀌었으니 에디터를 닫고 전체 빌드부터 해야 합니다.

## 완료한 작업

| 영역 | 내용 |
| --- | --- |
| 체력 3칸 | 플레이어·적 MaxHealth 3. 파랑 펠릿은 대상당 1회만 데미지(VolleyId). 하트 위젯 WBP_HealthChunks를 머리 위에 표시, 적은 조준 중일 때만 |
| 게이지 UI | 방패 왼쪽 · 발열 오른쪽 · 구르기 아래. 과열은 깜빡임 없이 단색 |
| 배경음 | 타이틀/퍼즐/전투 곡 크로스페이드(LumenMusicSubsystem). 음악·효과음 볼륨 분리 |
| 효과음(기존) | 발사, 반사, 피격, 사망, 공격 예고, 발걸음 |
| 효과음(추가) | 전투: 구르기, 방패 들기·내리기·깨짐·막힘, 색 전환, 빈 격발, 과열 시작·해제. 퍼즐/환경: 센서 활성·색 불일치, 문 열림·닫힘, 퍼즐 클리어, 체크포인트, 거울 초기화 |
| 모션·총기 | 이동 Blend Space, 상체 사격 몽타주, 구르기(제자리), 사망. 총 3종 색별 자동 교체. 방패 자세는 LocoShield 캐시 포즈 구조 |
| 고정 포탑 | 감지 범위 안 플레이어를 향해 회전(초당 120°), 정면 8° 안에 들어오면 공격. 예고선 방향으로 고정 발사. 공격은 사거리 90% 안에서만 |
| 조준선·총구 | 조준선 길이 = 실제 사거리(크기 무시). 조준선·발사체·레이저가 Muzzle 소켓에서 시작. 플레이어는 총구에서 커서 지점으로(80cm 안이면 몸 방향) |

**고친 버그**

- 초록 레이저를 피할 수 없던 문제: 발사 시 다시 조준하던 것을 예고선 방향 고정으로 변경
- 포탑 조준선만 길어 보이던 문제: 조준선이 액터 Scale을 무시하도록 수정
- 포탑 발사 위치가 총구와 다르던 문제: 소켓을 포탑 메시에서 먼저 찾고, 숨겨진 메시는 건너뜀
- 파랑 포탑이 자기 탄에 맞던 문제: 반사 전 탄은 쏜 사람을 무시(반사된 탄은 맞음)
- 벽에 붙으면 조준선이 벽 너머에서 시작되던 문제: 몸 중심→총구 사이에 벽이 있으면 벽 앞에서 시작

## 맵 구성·조명 방향

천장 없는 실내로 갑니다. 쿼터뷰에서 천장 생략은 장르 관습이라 야외로 읽히지 않고, 어두운 실내가 3색 빛을 가장 잘 살립니다.

- 하늘: Sky Atmosphere·Directional Light는 끄거나 아주 약하게, 배경은 검정·짙은 남색
- Sky Light 0.1~0.3, Exponential Height Fog는 검정·남색
- 주광원은 맵 안 조명(벽등, 바닥 조명, Emissive). 방마다 색 톤을 달리해 퍼즐룸·전투룸 구분
- 시간대는 정하지 않음 (시간이 없는 공간)
- 그림자만 필요하면 천장 메시를 두고 Visible 끄기 + Cast Hidden Shadow 켜기
