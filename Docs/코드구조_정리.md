# LUMEN 소스 구조 정리 — 주석 정리 + 기능별 폴더 이동 계획

2026-10-15

## 1. 이번에 바뀐 것 (이미 반영됨)

- **주석만 정리** (Source/Lumen 아래 75개 파일). 코드는 바뀌지 않았음 — 주석을 걷어낸 코드끼리 비교해서 원본과 같은지 확인함.
  - 헤더 맨 위에 클래스 역할과 연결 대상 1~3줄, 멤버는 `// ===== 그룹 =====` 구분선으로 묶음
  - 주차·작업 태그(`[사운드]`, `← 추가`, `N주차`, 문서 장 번호), Epic 템플릿 문구, 이미 바뀐 설계 설명(거리 감쇠, 숫자 HP바, 5칸 HP 등)을 지움
  - 코드와 맞지 않던 주석은 코드 기준으로 수정 (하트 위치는 "발밑"이 아니라 "머리 위", 적 Tick은 켜져 있음, 소켓 탐색 순서 등)
  - "왜 이렇게 했는지"(RoomToReset 복사, 첫 세그먼트만 자기 무시, 거울 반사=거리 리셋/방패=누적 등)는 남기고 현재형으로 다듬음
  - 주석 처리된 코드 줄(`// UE_LOG(...)` 등)은 지우지 않음
- **include를 파일 이름만 쓰도록 통일**: `"Lumen/Reflection/Projectile.h"` → `"Projectile.h"` 등 (22곳).
- **Lumen.Build.cs**: 모듈 폴더 아래 모든 하위 폴더를 include 경로에 자동 추가. 그래서 지금 위치에서도 빌드되고, 아래처럼 폴더를 옮겨도 include를 고칠 필요가 없음.
- **Reflective.h** 인코딩을 CP949 → UTF-8로 변환 (다른 파일과 통일).

## 2. 기능별 폴더 이동 계획 (직접 옮겨야 함)

`Source/Lumen/` 기준. `Lumen.h`, `Lumen.cpp`, `Lumen.Build.cs`는 그대로 루트에 둔다. 각 클래스는 `.h`와 `.cpp`를 같은 폴더에 둔다.

| 새 폴더 | 옮길 파일 (현재 위치) |
|---|---|
| **Core/** | LumenGameMode.h/.cpp (루트), LumenPlayerState.h/.cpp (루트), LumenGameUserSettings.h/.cpp (루트), LumenMusicSubsystem.h/.cpp (루트), LumenGameInstance.h (Public) + .cpp (Private), LumenSaveGame.h (Public) |
| **Character/** | LumenCharacter.h/.cpp (루트), LumenAimLineComponent.h/.cpp (루트), ShieldActor.h (Public) + .cpp (Private) |
| **Combat/** | WeaponDataAsset, HealthComponent, HeatComponent, LumenCombatLibrary, LumenBeamSegment, LightEmitterActor — 모두 .h (Public) + .cpp (Private). LumenCollisionChannels.h (Public) |
| **Reflection/** | 그대로 (Reflective, MirrorActor, Projectile) |
| **AI/** | LumenEnemyCharacter, LumenEnemyAIController, BTService_LumenPerception, BTTask_LumenFireWeapon, BTTask_LumenTelegraph, BTTask_LumenHideTelegraph — 모두 .h (Public) + .cpp (Private). LumenAITypes.h (Public) |
| **Level/** | RoomVolume, CombatRoomVolume, PuzzleRoomVolume, PuzzleSensorActor, PuzzleResetActor, LumenDoorActor, CheckpointActor, LumenKillZVolume — 모두 .h/.cpp (루트). LumenInteractable.h (루트) |
| **UI/** | LumenHealthChunksWidget, LumenPlayerGaugesWidget, LumenInteractPromptWidget — 모두 .h/.cpp (루트) |
| **Test/** | TestActor.h/.cpp — 어떤 코드도 참조하지 않음. 레벨에 배치된 게 없으면 삭제 후보 |

다 옮기면 `Public/`, `Private/` 폴더는 비게 되니 삭제.

### 옮기는 순서

1. 지금 주석 정리분을 먼저 빌드 확인 후 커밋 (폴더 이동과 커밋 분리)
2. 에디터와 Visual Studio를 닫음
3. 위 표대로 파일 이동 (`git mv`를 쓰면 이력이 깔끔하게 이어짐. 탐색기로 옮겨도 내용이 같아서 git이 이름 변경으로 인식함)
4. 빈 `Public/`, `Private/` 삭제
5. `Lumen.uproject` 우클릭 → **Generate Visual Studio project files**
6. 전체 빌드. include 수정은 필요 없음
7. 블루프린트는 클래스 이름과 모듈 이름으로 연결되므로 파일 위치가 바뀌어도 깨지지 않음

## 3. 주석 정리 중 발견한 코드 의심 지점 (수정하지 않음)

우선순위 높은 것부터.

| 위치 | 내용 |
|---|---|
| PuzzleRoomVolume.cpp ~75 | ApplyRoomView 직후 `SetRoomMask(true, …)`를 다시 호출 → `bMaskOutsideRoom` 설정이 무시됨 |
| PuzzleRoomVolume.cpp ~89 | 이탈 시 `SetRoomMask(false, …)`를 조건 없이 호출 → 이미 옆 방에 들어갔다면 그 방 마스크까지 꺼짐 (ActiveViewRoom 보호 우회) |
| BTTask_LumenTelegraph.cpp ~61 | `OnTaskFinished` 오버라이드가 있는데 생성자에서 `bNotifyTaskFinished = true`를 안 켬 → 태스크 중단 시 텔레그래프가 안 꺼질 수 있음 |
| LumenCombatLibrary.cpp ~139 | 초록 레이저는 방패 반사 시 DamageCauser까지 방패 주인으로 바꿈. 발사체는 Instigator만 바꿈 — 규칙 불일치 |
| LumenCombatLibrary.cpp ~181 | 관통+반사로 같은 적을 다시 지나가면 한 발에 여러 번 데미지 가능 (VolleyId 같은 장치 없음) |
| LightEmitterActor.cpp ~59 | 펠릿에 VolleyId를 안 넣음 → 이미터가 파랑을 쏘면 펠릿마다 데미지 |
| ShieldActor.cpp ~15 | `ShieldBoxExtent`(EditDefaultsOnly)를 생성자에서 적용 → BP에서 바꾼 값이 반영 안 될 수 있음 |
| HealthComponent.cpp ~118 | `GetFilledChunkCount`는 NumHealthChunks가 0이면 0으로 나눔 |
| LumenCharacter.cpp ~977 | 리스폰 시 방패 게이지 리셋이 HeatComponent를 찾았을 때만 실행됨 |
| LumenCharacter.cpp / LumenEnemyCharacter.cpp | 생성자의 `SetPivot(0.5, 0)`은 BeginPlay의 `SetPivot(0.5, 1)`이 덮어써서 무의미 |
| LumenCharacter.cpp ~432 | 이동 입력이 월드 X/Y 그대로 — 카메라 Yaw가 45도면 화면 방향과 어긋날 수 있음 (의도라면 무시) |
| LumenGameInstance.cpp | SaveVersion을 저장만 하고 로드 때 확인하지 않음 |

### 죽은 코드 (정리 후보)

- `ALumenCharacter::SetCurrentCombatRoom` / `CurrentCombatRoom` — 어디서도 안 씀
- `APuzzleRoomVolume::SensorGroupID` — 안 씀
- `ELumenAttackState::Cooldown`, BB 키 `NextCooldownDuration` — C++에서 값을 안 씀
- `UHealthComponent` — Tick 내용이 전부 주석 처리된 빈 Tick, `DebugPrintHealth`/`DebugPrintDeath`/`UpdateHealthDebugDisplay` 호출처 없음
- `UHeatComponent::DebugPrintHeat` — 본문 비어 있고 바인딩 안 됨
- `BTService_LumenPerception`의 `AShieldActor` 분기 — 방패가 Visibility를 무시하므로 실행될 일 없음
- `AProjectile` 기본값 Speed 2000 / Damage 10, `DamageCauserActor` — InitFromWeaponData가 항상 덮어씀
- `LumenGameMode` — 템플릿 `BP_ThirdPersonCharacter` 경로가 하드코딩. 실제 게임 모드가 BP라면 미사용
- `LumenCharacter.cpp`에 `#include "WeaponDataAsset.h"` 중복
- 주석 처리된 `UE_LOG` 줄 다수 (LumenCharacter, ShieldActor, LightEmitterActor, EnemyAIController, BTService, Health/HeatComponent)
